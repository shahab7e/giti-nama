# جام جهان‌نما

نمودار زمانی تاریخ جهان با محوریت ایران. ایران همیشه بالای صفحه ثابت است و سرزمین‌های دیگر زیر آن می‌آیند، تا دیده شود هم‌زمان با هر دوره از تاریخ ایران، بقیهٔ دنیا چه خبر بوده است.

**نسخهٔ آنلاین:** https://shahab7e.github.io/jam-jahan-nama/

ایده از نمودارهای چاپی «ظهور و سقوط ملت‌ها» گرفته شده است: هر حکومت یک شکل رنگی است و ضخامتش با وسعت قلمروش در هر سال کم و زیاد می‌شود.

## چه چیزهایی دارد

- **۶۴۵ حکومت و تمدن، ۶۳۲ فرمانروا، ۴۷۴ رویداد و ۱۶۰ چهره** در ۲۷ سرزمین، از نوسنگی زاگرس تا امروز
- **ایران به‌عنوان محور:** دوره‌ها، دودمان‌ها، فرمانروایان و رویدادهای ایران در نوار بالایی، و دودمان‌های محلی و چهره‌های ایرانی در ردیف‌های «ایران از نزدیک»
- **برش زمان:** با کلیک روی یک سال، یا انتخاب یک حکومت، رویداد یا فرمانروا، ستون کناری هر آنچه در همان بازه در جهان بوده را نشان می‌دهد. فهرست سه بخش دارد: حکومت‌ها و فرمانروایان، رویدادها، و چهره‌ها.
- **سیطرهٔ امپراتوری‌ها:** نوار «زیر فرمان …» نشان می‌دهد هر سرزمین در چه سال‌هایی زیر فرمان کدام امپراتوری بوده است، مثلاً هخامنشیان بر عراق و مصر یا عثمانی بر شام. با کلیک روی یک امپراتوری، همهٔ سرزمین‌هایش پررنگ می‌شوند.
- **فیلتر سرزمین‌ها:** می‌توانید فقط چند سرزمین را انتخاب کنید تا درست زیر ایران و کنار هم دیده شوند.
- **تقویم سه‌گانه:** سال میلادی در بالا، و خورشیدی و قمری در پایین نمودار
- **جست‌وجو، دکمه‌های پرش به دوره‌ها، حالت تیره، و نمای موبایل**

## راهنمای استفاده

| کار | روش |
|---|---|
| جابه‌جایی در زمان | کشیدن نمودار |
| بزرگ‌نمایی | چرخ موس یا دو انگشت |
| پیمایش سرزمین‌ها | کشیدن عمودی، یا Shift و چرخ موس |
| ثابت‌کردن برش زمان | کلیک روی نمودار |
| پاک‌کردن انتخاب | کلید Esc |

## اجرا روی کامپیوتر خودتان

پروژه هیچ وابستگی و مرحلهٔ ساختی ندارد. فقط باید پوشه را با یک سرور ساده باز کنید:

```bash
python -m http.server 8765
```

بعد نشانی `http://localhost:8765` را در مرورگر باز کنید.

## ساختار پروژه

```
index.html          صفحهٔ اصلی
css/style.css       ظاهر
js/core.js          ثبت داده‌ها و ابزارهای تاریخ و عدد فارسی
js/render.js        کشیدن نمودار روی canvas
js/app.js           کلیک، جست‌وجو، فیلتر و ستون برش زمان
data/               همهٔ داده‌های تاریخی
tools/validate.mjs  بررسی درستی داده‌ها
tools/build.mjs     ساخت نسخهٔ تک‌فایلی در dist/jam.html
```

## افزودن یا اصلاح داده‌ها

همهٔ داده‌ها در پوشهٔ `data/` و به شکل آرایه‌های ساده‌اند. سال‌های پیش از میلاد منفی نوشته می‌شوند (`-550` یعنی ۵۵۰ پ.م).

**حکومت:** `[شناسه، نام، نام لاتین، آغاز، پایان، {گزینه‌ها}]`

```js
TL.addPolities('iran', [
  ['achaemenid', 'هخامنشیان', 'Achaemenid Empire', -550, -330, { lv: 1, cap: 'پاسارگاد، شوش، تخت جمشید', d: '...' }]
]);
```

گزینه‌ها: `lv` اهمیت (۱ رشتهٔ اصلی، ۲ دودمان بزرگ، ۳ محلی)، `a` تاریخ تقریبی، `cap` پایتخت، `d` توضیح، `k: 'culture'` برای فرهنگ‌ها، `c` فام رنگ.

**فرمانروا:** `[نام، نام لاتین، آغاز، پایان، {d, t, a}]`، با شناسهٔ حکومتش:

```js
TL.addRulers('achaemenid', [['کوروش بزرگ', 'Cyrus the Great', -559, -530, { d: '...' }]]);
```

**رویداد:** `[سال، عنوان، {y2, k, w, d, a}]`. `k` نوع رویداد است (`pol` سیاسی، `war` جنگ، `cul` فرهنگ، `sci` دانش، `rel` دین، `dis` بلا، `eco` اقتصاد) و `w` اهمیت آن از ۱ تا ۳.

**چهره:** `[نام، نام لاتین، زاده، درگذشت، گونه، {d, a}]`. گونه یکی از `poet`، `sci`، `phil`، `rel`، `art`، `pol`، `mil` یا `exp` است.

**سیطره:** در `data/dominion.js` مشخص می‌شود هر حکومت محلی زیر فرمان کدام امپراتوری بوده است:

```js
mes_ach: 'achaemenid',                        // هخامنشیان در میان‌رودان
mes_mac: ['alexander', 'seleucid'],           // پشت‌سرهم
```

**وسعت قلمرو:** در `data/extent.js`، به میلیون کیلومتر مربع؛ یا یک عدد بیشینه، یا چند نقطهٔ `[سال، مساحت]`.

پس از هر تغییر، داده‌ها را بررسی کنید:

```bash
node tools/validate.mjs
```

این اسکریپت شناسه‌های تکراری، سال‌های ناسازگار، سرزمین‌های ناشناخته و پیوندهای سیطرهٔ بی‌هم‌پوشانی را گزارش می‌دهد.

## نسخهٔ تک‌فایلی

```bash
node tools/build.mjs
```

همهٔ فایل‌ها را در `dist/jam.html` کنار هم می‌گذارد تا بشود صفحه را جای دیگری منتشر کرد.

## دربارهٔ دقت

تاریخ‌های کهن، به‌ویژه پیش از هزارهٔ یکم پ.م، تقریبی‌اند و در نمودار با لبه‌های محو نشان داده می‌شوند. وسعت قلمروها برآوردی‌اند و بیشینه‌هایشان بیشتر از فهرست «بزرگ‌ترین امپراتوری‌ها»ی ویکی‌پدیا آمده است. اگر خطایی دیدید، یک issue باز کنید یا خودتان اصلاحش را بفرستید.
